## 关键架构决策

- 三维持久化和展示唯一基准为 EPSG:4490。
- EPSG:4547 仅在受控米制分析适配层出现，算法结果标明本地结果空间与 4490 展示目标。
- `entranceId/sensorId/facilityId/modelObjectId/leakSourceId` 通过空间资产清单绑定。
- 场景切换先预检后替换；失败保持主场景。
- 实时链使用 HTTP + SSE，不引入 MQTT 和新依赖；SSE 使用一次性短票据、并发上限和无缝回放同步边界。
- 新能力按场景、SSE、扩散/KDE、二维瓦片设置独立开关。

## 剩余风险

- 出入口 4490 点为现有配准锚点和二维资产计算结果；正式交付前仍需在 iDesktopX 中对模型门位人工点选校核。
- 六个旧独立场景实际位于远端 18090，源坐标为本地米制；代理和数据名已修正，但远端服务当前不返回 HTTP，不能验证成功瓦片。
- iPortal 远端服务需服务器侧检查进程、许可、数据库、磁盘和资源权限。
- Python HTTP 测试环境缺 `httpx2`；未获批准前未新增依赖。
- ESLint 仍报告 `SuperMapSceneViewer.vue` 中 18 个既有未使用变量/函数；本轮没有扩大范围清理。
- 曾出现在本地前端环境文件中的外部 API 值已移除；相关外部凭据仍应在供应商控制台轮换。
