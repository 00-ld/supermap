## 五大核心模块

### 1. 气体监测与仿真读数
当前仓库没有真实硬件采集链路，也没有独立的实时采样存储系统。监测读数以 `sensor_reading`
表承载可追溯仿真/采样记录，并用 `source=simulation`、`quality_status=SIMULATED`
标明数据来源；`warning_history` 只作为告警事件列表，不再作为实时采样、趋势或读数兜底。

### 2. 分级及时预警
配置多级预警阈值，异常数据自动触发告警，联动溯源模块启动应急流程。

### 3. 泄漏源估计
基于多点浓度观测、物理信息深度学习响应模型与粒子滤波反演估计候选泄漏源位置，并输出误差、置信信息和适用边界。当前深度学习层由 PyTorch MLP 学习扩散响应，并以物理扩散核作为安全锚点；CFD 可作为后续高保真验证方向，不在当前仓库中冒充已完成的生产级能力。

### 4. 三维可视化
优先接入 SuperMap iPortal 已建设数字大屏，展示园区三维场景、监控点位、巡检小车、泄漏点和险情态势；Three.js/SuperMap 原生三维能力作为后续扩展，Canvas 承载二维态势地图。

### 5. 智能小车调度
D\* Lite 算法实现动态应急避障路径规划。当前小车页面接入的是巡检图片识别、巡逻动画和告警联动，不具备真实车载传感器连续采样链路。

## 算法模块

| 算法 | 模型 | 用途 |
|------|------|------|
| 气体扩散 | 物理信息深度学习代理模型 | 在原有地图边界、障碍、道路通道和阈值约束下模拟 CO、O2、NH3、CH4 浓度扩散趋势 |
| 真实扩散校验 | Prairie Grass + FB/NMSE/FAC2 | 使用真实野外实验的横风向扩散宽度 `Sy (m)` 校验扩散尺度，不扩大解释为绝对浓度验证 |
| 泄漏溯源 | 深度学习响应模型 + 粒子滤波反演 | 估计候选泄漏源位置，输出误差和置信信息 |
| 路径规划 | D\* Lite | 根据危险浓度区域生成和更新逃生路线 |
| 点位布局 | 规则约束 + 后续优化模型 | 依据标准和风险区域优化监控点位布局 |
| 视觉识别 | YOLO11m | 识别小车摄像头图像中的人员位置 |
| 高保真校验 | CFD/实测数据对比 | 后续验证方向，需单独记录数据来源和边界 |

## 数据流转

```
仿真读数/手工观测/巡检图片素材 → Java 后端 → Python 扩散、溯源与规划服务 →
D* Lite 路径规划 → 前端 Canvas 与 SuperMap iPortal 展示 →
告警联动、识别记录与后续验证台账
```
