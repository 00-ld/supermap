# SuperMap 二三维同场景切换

## 目标

- 参考 SuperMap 官方 `sceneModeSwitching` 示例，在同一个 Viewer 内切换平面场景与三维场景。
- 场景、相机、拾取结果和对外算法结果继续统一使用 CGCS2000 / EPSG:4490，不复制示例坐标或服务 URL。
- 切换时不卸载 S3M、3D Tiles、扩散、溯源和疏散图层，不影响当前可演示基线。

## 实施

- 将 Viewer 的 `scene3DOnly` 从 `true` 调整为 `false`。
- 新增 `setSceneProjectionMode('2d' | '3d')`：
  - 优先调用 `scene.morphToColumbusView(0.85)` / `scene.morphTo3D(0.85)` 实现平滑切换；
  - SDK 未暴露 morph 方法时，兼容官方示例的 `scene.mode` 赋值；
  - 进入平面前保存当前三维相机，返回三维后平滑恢复；
  - 平面视角使用项目既有 EPSG:4490 园区锚点，不使用示例中的经纬度。
- `/screen` 不再交换 SuperMap 与独立二维工作区的主副屏尺寸；新增“平面 / 三维”切换按钮，二维业务地图仍作为右上角分析预览保留。
- 坐标状态栏只展示 EPSG:4490 经纬度和高程。EPSG:4547 仅保留在距离、缓冲、路网等内部米制计算适配层，不作为场景或对外结果坐标。

## 问题与解决

1. 原界面的“二维/三维”只是 CSS 交换两个组件，且 Viewer 设置了 `scene3DOnly: true`，无法使用官方场景模式。
   - 解决：开放 Viewer 场景模式，在同一实例内 morph，避免图层重新请求。
2. 修改后检查时 5173、8000、8090 均无监听。
   - 解决：分别以隐藏后台进程恢复 Vite、算法服务和现有本地 iServer；未执行生产构建，也未重启已恢复的服务。
3. 旧服务名 `3D-ChemicalPark` 返回 404。
   - 根因：当前发布清单实际服务为 `3D-local3DCache-huangong`。
   - 解决：以实际 config 地址复核，返回 200。
4. Playwright CLI 启动 Chrome 时系统返回 `spawn UNKNOWN`。
   - 处理：停止重复拉起浏览器，改用类型检查、单元测试、空间契约校验和 HTTP 存活检查，避免影响演示进程。

## 回滚

- 回滚 `setSceneProjectionMode` 和 `/screen` 切换按钮。
- 将 Viewer `scene3DOnly` 恢复为 `true`。
- 恢复原 `two-d-primary` 主副屏 CSS 即可回到旧版双组件切换；空间数据与服务未被改写，无需数据回滚。
