## 空间主数据绑定

不应把实时浓度或算法帧写进 S3M 模型。需要在同一工作空间发布稳定点/线数据集：

| 资产 | 稳定字段 | 运行数据关联 |
|---|---|---|
| 出入口 | `EntranceID, ModelObjectID, FacilityID, RoadNodeID, Elevation, Camera*` | 路径终点、三维标记、近景相机共用 `EntranceID` |
| 传感器 | `SensorID, ModelObjectID, FacilityID, InstallHeight, ObservedProps` | `sensor_reading.sensor_id + gas_code + sampled_at` |
| 泄漏源候选 | `LeakSourceID, ModelObjectID, FacilityID` | 扩散任务绑定 `LeakSourceID + gasCode` |
| 道路 | `RoadNodeID, RoadEdgeID` | 路径规划输入和出入口吸附 |

本地 `data-chemicalplant` 已发布 `DevicePoint_2D_P`，包含 `SensorID、FacilityId、InstallHeight、ObservedProps、Wgs84Lon/Lat、View*` 等传感器/视角字段；当前没有 `Park_EntrancePoint_P`，因此出入口仍无法从发布服务取得模型实测点位。下一步必须在 iDesktopX 对模型门位点选后创建该数据集，不能继续使用前端估算坐标。

当前四个入口已标记为 `UNVERIFIED`。正式算法、3D Tiles、默认 S3M 和本地回退路径均会拒绝用这些估算点进行疏散规划；只有发布数据回读并校验后改为 `PUBLISHED` 才会开放相机定位和路径终点计算。
