# 阶段 4：扩散与溯源三维

## 完成内容

- 天气实况继续由 `environmentSnapshot` 自动绑定风速、风向、温度、湿度、来源和观测时间。
- 算法结果增加空间元数据：输入空间、4547 分析 CRS、本地米制结果空间、4490 展示 CRS 和转换版本。
- 粒子滤波最少需要 3 个有效传感器，不足时返回明确校验错误。
- 统一溯源事件携带 `posteriorDensityGeoJSON` 和 `credibleRadius95m`。
- 三维阶段真正调用既有 KDE 面渲染；颜色、高度/材质和透明度只按归一化后验密度表达。
- 无有效 KDE 时降级显示估计点和 95% 置信区，不伪造概率云。

## 约束与收获

- 算法仍在局部米制平面运行，结果由唯一场景转换链落到 4490。
- 现有实体扩散渲染继续作为安全回退，没有新增第三方依赖。
- 前端可用 `VITE_FEATURE_INVERSION_KDE_3D=false` 单独关闭 KDE。

## 验证

- Python HTTP 契约测试已补空间元数据和少于 3 个传感器用例。
- 当前虚拟环境缺少 Starlette 新版要求的 `httpx2`，按“不新增依赖”约束未安装；此项记录为验证环境阻塞，不掩盖。
