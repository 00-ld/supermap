# 阶段 3：HTTP + SSE 实时传感器链

## 完成内容

- 新增单条、500 条有界批量、分页最近读数和 SSE 流接口。
- `eventId` 唯一索引实现幂等；`Last-Event-ID` 按数据库 ID 最多回放 500 条。
- SSE 连接先通过已登录请求取得 10 分钟一次性短票据；票据消费即失效，并设置 100 条全局并发上限。
- 回放查询、订阅登记和实时发布使用同一同步边界，消除回放与订阅之间的漏事件窗口。
- 点位只从注册 `sensorId` 解析，拒绝未知传感器。
- 校验气体代码、非负浓度、单位、未来时间、来源和质量状态。
- `hardware/simulation/simulator/manual` 与 `VALID/SIMULATED/INVALID/STALE/CALIBRATING` 分离。
- 模拟来源强制标记 `SIMULATED`，日志不记录完整载荷。
- 前端原生 EventSource；断线指数退避，断线期间 5 秒有界轮询，恢复后停止轮询。
- 组件卸载和并发连接使用连接代次门禁；算法观测按当前事故 `gasCode`、有效质量状态和 60 分钟窗口统一筛选后换算为 ppm。
- 本地模拟器：`tools/simulate-sensor-readings.ps1`。

## 数据库

执行 `db/migrations/006_add_realtime_sensor_reading.sql` 后：

- 17 条历史读数全部获得 `legacy-<id>` 事件 ID。
- `COUNT(*)=17`，`COUNT(DISTINCT event_id)=17`。
- `uq_sensor_reading_event_id` 唯一索引存在。

## 冒烟证据

- 首次投递：`ACCEPTED`。
- 相同 eventId 重投：`DUPLICATE`。
- 最近读数：返回 3 条。
- 模拟读数质量：`SIMULATED`。
- SSE：收到 `event:connected` 和 `data:sensor-reading-stream`。

## 回滚

- 前端设置 `VITE_FEATURE_SENSOR_SSE=false` 后只使用有界轮询。
- 数据库回滚仅删除新唯一索引和新列；执行前必须先备份，不能删除历史读数。
