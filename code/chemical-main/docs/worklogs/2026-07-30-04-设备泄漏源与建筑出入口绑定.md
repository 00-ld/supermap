## 空间落点规则

### 泄漏源

- 使用设备模型的 EPSG:4490 包围体。
- 点位放在设备包围体东侧约 90% 半径处，高度采用 `SmMinZ + 35% × (SmMaxZ - SmMinZ)`。
- 该位置避免落在设备几何中心，适合后续体泄漏从设备侧壁沿法向释放。
- `SurfaceNormalX/Y/Z` 当前为 `(1, 0, 0)`；后续若完成网格射线求交，可替换为真实模型表面法向。

### 建筑出入口

- 使用 `REG_BUILDING_*` 模型包围体南侧边界中点。
- 向南外移 1.5 米，避免标记落入建筑中心。
- 高度采用 `max(SmMinZ, 0) + 1.2m`。
- 由于尚未引入道路中心线，当前记录的 `CandidateReason` 明确标注为自动立面候选。

## 遇到的问题

### Recordset.add 第二条记录失败

原因：iObjectsPy 文档要求新增记录前进入编辑模式。

解决：对两个输出记录集调用 `batch_edit()`，全部写入后调用 `batch_update()`。

### batch_update 返回值不能作为成功依据

现象：`batch_update()` 返回非真值，但泄漏源的 32 条记录已经持久化。

解决：不再依赖该返回值，改为刷新数据源后用实际记录数与名称匹配计数做强校验。

### iObjectsPy 报告缺少 NumPy

影响：启动时仅禁用 `ml.utils`，本次矢量数据读写和坐标处理不依赖 NumPy，任务成功完成。

处理：本阶段不新增或升级依赖，避免改变 iDesktopX 2026 自带 Python 环境。
