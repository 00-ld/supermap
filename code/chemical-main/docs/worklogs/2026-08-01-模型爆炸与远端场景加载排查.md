## 四、根因分析（三层问题）

### 4.1 2026 SDK 与远端 2025 iServer 的隧道加密不兼容（阻断）

- 本地 8090 = **SuperMap iServer 2026**（项目 SDK 来源）；远端 18090 = **SuperMap iServer 2025 Update1**
- 2026 SDK 的 `Mei`/`Rei`（`encryptionCheckLicense`/`encryptionRequest`）对任何 iServer 请求**无条件启用加密隧道**：`!sessionStorage.tunnelUrl` 时强制 `Lei()` 创建隧道，且 **license.json 永远走隧道转发**
- 2026 SDK（AES-GCM+RSA 加密）与 2025 服务器解密不兼容 → `InvalidCharacterError: atob` / POST 400 "Parsing cipher text failed" / GET tunnels 404 → license 校验失败 → **图层初始化卡死 → 瓦片 0**
- 已尝试的绕过均失败：
  - 代理改写响应中绝对地址（`8.130.175.232:18090` → 同源）——隧道改走代理但仍失败
  - 伪造隧道创建响应（`blockedUrlRegex` 全匹配）——SDK 仍轮询隧道 GET 400
  - `sessionStorage` 预置（`tunnelUrl` 非空 + `blockedUrlRegex` 空）——JSESSIONID 条件仍触发 `Lei()`，且 license 无条件隧道转发无法绕过；本地组合下预置有效（瓦片 225），远端组合无效

### 4.2 2025 SDK 瓦片调度不启动（谜团未解）

- 2025 SDK + 远端 2025 服务器：版本匹配，无隧道问题，数据请求全部正常，`datasetInfo()` 成功（爆炸分层可用），但 `_tilesWaiting=0/_tilesLoading=0`、s3mb=0
- 已尝试：`zoomTo`、手动 `setView` 到模型中心、`cullEnabled:false`、`scene.requestRender()` 强制帧、`scene.open()` 打开 realspace 场景、headed 模式（真实 GPU，未完成）——均未触发瓦片请求
- 疑似方向（未证实）：2025 SDK 对局部坐标系/独立图层加载的瓦片调度依赖某个未满足的前置条件；或 headless SwiftShader 下渲染循环异常（headed 实验未跑完）

### 4.3 远端服务数据能力不足（爆炸效果降级）

- 六个远端 3D 服务未启用对象属性查询（attributeQuery/objectQuery 404），无构件中心点数据服务 → 官方新版"发散爆炸"无法实现，只能做按 SmID 分层的"抽屉式"近似效果
