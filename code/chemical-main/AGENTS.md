# 项目全局规则

- 本项目在 Windows 本地开发时，默认使用根目录 `startup.bat` 一键启动 MySQL、Python 算法服务、YOLO 人员识别服务、Java 后端和前端开发服务。
- 如果任何服务的启动命令、端口、环境变量、数据库初始化方式或启动顺序发生变化，必须同步更新 `startup.bat`，并在相关文档中保持一致。
- 不得把真实数据库密码、JWT 密钥、算法密钥或其它敏感凭据写入仓库。`startup.bat` 只能读取环境变量或在本机交互输入。
