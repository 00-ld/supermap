## 报告取图建议

1. 桌面端瓦片处理环境：使用 `01-idesktopx-2026-main.png`。
2. 瓦片加载入口：使用 `11-tile-dropdown.png`、`12-load-tile-file-dialog.png`。
3. 三维场景加载成果：使用 `47-idesktop-locate-key-result.jpg` 和 `48-idesktop-current-after-user-input.jpg`。
4. Web 端系统入口成果：优先使用 `68-web-screen-scene-open-autoview-model.png`，`53-web-screen-supermap3d-ready-model.png` 作为历史有效截图。
5. 坐标事实边界说明：使用 `69-web-screen-local-epsg0-scene-before-algorithm.png`。
6. Web 端二维地图成果：优先使用 `55-web-smartmap-supermap2d-real-backend.png`，`54-web-smartmap-supermap2d-ready.png` 作为补充。
7. 二维道路/建筑识别成果：使用 `../二维数据集识别/dataset_qa_overlay.png`，并配合 `supermap_udbx/chemical_park_vectors.udbx` 说明已经生成 SuperMap 数据源。
